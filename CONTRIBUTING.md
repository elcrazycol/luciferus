# Контрибьютинг

Спасибо, что зашёл. Проект задуман так, чтобы **добавить свою игру мог любой** — даже
без глубокого знания нашего кода. Если ты хочешь просто выложить игру на платформу,
загляни в `docs/GAME_AUTHORING.md`, когда он появится (фаза 2). Ниже — про код.

## Требования

- **Bun ≥ 1.2** — пакетный менеджер и рантайм (`curl -fsSL https://bun.sh/install | bash`)
- **Docker** — Postgres и Redis
- Никаких других глобальных установок не нужно

## Локальный запуск

```bash
bun install
cp .env.example .env
bun run infra:up        # поднимает Postgres + Redis
bun run db:migrate
bun run db:seed
bun run dev             # portal :3000, api :3001
```

Тесты и проверки:

```bash
bun run typecheck
bun run test
bun run lint
bun run lint:fix        # автофикс (Biome)
```

## Правила

1. **Один PR — одна мысль.** Не смешивай рефакторинг и фичу.
2. **Проверки должны быть зелёными.** CI гоняет lint, typecheck и тесты.
3. **Деньги — только через леджер.** Любая операция с балансом идёт через сервис
   кошелька, пишет запись в `ledger` и обновляет `wallets` в одной транзакции.
   Прямой `UPDATE wallets` в обход леджера не пройдёт ревью.
4. **Валидация на границе.** Всё, что приходит снаружи (HTTP, WebSocket, postMessage),
   проверяется схемами Zod из `packages/protocol`.
5. **Никаких реальных денег.** PR, добавляющий платёжную интеграцию, будет закрыт.
6. **Не ломай вайб.** Если меняешь UI — приложи скриншот или короткое видео.
7. **Коммиты на английском**, в формате Conventional Commits:
   `feat(wallet): add reload bonus cooldown`.

## Стиль кода

Настраивать ничего не надо — Biome отформатирует и подсветит проблемы:
