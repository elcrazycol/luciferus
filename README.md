# 🎰 LuciferusCasinos

Опенсорсная платформа-обёртка «онлайн-казино» на **фейковом балансе**. Выглядит и ведёт
себя как настоящее казино, но денег здесь нет: валюта — **C$ (CrazyBucks)**, и она ничего
не стоит.

Главная идея: **портал — это хост и кошелёк, а не игровой движок.** Свою игру можно
написать на чём угодно, задеплоить куда угодно и подключить к платформе одной строкой.

```html
<script src="http://localhost:3000/sdk/v1.js" async></script>
```

Дальше игра получает готовый объект: баланс игрока, ставки, выплаты, чат, presence и
честный рандом. Портал сам рисует лобби, кошелёк, историю ставок, лидерборды и
провайдеров.

## Быстрый старт

Нужны **Bun ≥ 1.2** и **Docker**.

```bash
git clone https://github.com/your-org/LuciferusCasinos.git
cd LuciferusCasinos
bun install
cp .env.example .env

bun run infra:up     # Postgres + Redis в докере
bun run db:migrate   # миграции
bun run db:seed      # категории, игры-заглушки, боты, демо-аккаунты

bun run dev          # портал на :3000, API на :3001
```

Одной командой всё сразу: `bun run setup`.

### Демо-аккаунты из сидов

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin` | админ: модерация игр, корректировка балансов |
| `player` | `player` | обычный игрок с C$250 на счету |

Свой аккаунт — на странице `/register`: логин, отображаемое имя и пароль. Стартовый бонус
C$250 начисляется сразу.

## Что уже есть

- **Монорепа** на Turborepo + Bun workspaces.
- `packages/config` — единый конфиг валюты и экономики (C$, стартовый бонус, релоад).

- `packages/sdk` — SDK для игр: 16 КБ, без зависимостей, самодостаточный бандл для `<script>`.
- `packages/db` — схема на Drizzle (users, sessions, wallets, ledger, providers, games,
  game_versions), миграции и сиды.
- `apps/api` — Hono: health, каталог игр, аккаунты, кошелёк, игровые маршруты.
- `apps/portal` — Next.js: лобби, регистрация и вход, кошелёк с историей, запуск игр,
  гайд для авторов игр.
- `apps/example-game` — эталонный слот: живая документация и фикстура для тестов.
- `infra/` — Postgres 16 + Redis 7 в docker compose.
- Тесты и CI: lint, typecheck, 170 тестов против реальных Postgres и Redis.

### Подключение своей игры

```html
<script src="http://localhost:3000/sdk/v1.js" async></script>
```

Дальше игра получает готовый объект: баланс игрока, ставки, выплаты, отмену раунда и
отладочную панель. Подробный гайд — [`docs/SDK.md`](./docs/SDK.md) и страница `/developers`
на самом портале.

### Кошелёк

Единственный источник правды по балансу — таблица `ledger`, а `wallets.balance` — её кэш,
который обновляется в той же транзакции. Прямого `UPDATE wallets` в обход журнала в коде нет.

| Маршрут | Что делает |
|---|---|
| `POST /v1/auth/register` | аккаунт + кошелёк + стартовый бонус одной транзакцией |
| `POST /v1/auth/login` | сессия; время ответа одинаковое и для несуществующего логина |
| `GET /v1/wallet` | баланс, условия дозаправки, последние операции |
| `GET /v1/wallet/ledger` | журнал с курсорной пагинацией |
| `POST /v1/wallet/bet` | ставка, идемпотентная по ключу раунда |
| `POST /v1/wallet/payout` | выигрыш; невозможен без ставки и не удваивается |
| `POST /v1/wallet/rollback` | возврат ставки, если игра упала посреди раунда |
| `POST /v1/wallet/reload-bonus` | C$100, когда всё слито, с кулдауном |
